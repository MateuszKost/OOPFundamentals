# OOP Fundamentals

In this project I will try to explain the fundamentals of Object-Oriented Programming (OOP) in C#. It will include practical examples and theoretical explanations covering topics such as:
- What is OOP? Why and when to use it?
- Abstract classes vs Interfaces vs Virtual methods - differences and how to use them
- Access modifiers (public, private, protected, internal)
- Encapsulation - information hiding and controlled access
- Constructors and overloading
- Inheritance - "is-a" relationships
- Polymorphism - behavior overriding and dynamic dispatch
- Composition - "has-a" relationships and class collaboration
- Class vs Struct vs Record - types comparison and use cases
- Immutable vs mutable objects
- Method overriding vs method overloading
- Static vs instance members
- Object initialization patterns (e.g. object initializer, with-expressions for records)
- Documentation and proper code organization

In the next project you will find:
- Using interfaces for dependency injection (DI)
- Basic unit testing to validate OOP structures
- Saving/loading objects (serialization)

Goal: Build a complete, educational project that not only demonstrates OOP in practice but also serves as a learning reference with theory-backed examples and explanations.
